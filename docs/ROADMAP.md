## v1.1 —— 便捷性

用户抱怨最多的会是「每次都要切窗口再复制」，所以这一版全在解决这个。

- [ ] **全局热键**：`Ctrl+Alt+Space` 唤起一个只做搜索的小窗，
       `Enter` 直接复制并隐藏。不打开主界面。
- [ ] **快速输入**：选中条目后模拟键盘输入（不是粘贴），绕开剪贴板历史工具。
- [ ] **TOTP 支持**：存 `otpauth://` 种子，直接显示 6 位码并带倒计时。
       密钥管理场景下这几乎是必需项。
- [ ] **过期汇总**：启动时把「已过期 / 一周内到期」的条目列在一起看一眼。
      单条的过期时间与列表标记 v1.0.0 已经有了，缺的是汇总视图。

## 明确不做

- **无保护的导出。** 导出功能是有的（Excel，按专辑分表），但导的是明文 ——
  这是自觉的取舍：备份与迁移是真实需求，装作不存在只会让人用更危险的方式
  自己解决。导出与导入**始终**要求再输一次主密码，免密码模式也不豁免
  （详见 README「导入 / 导出」一节）。
- **通用格式导入。** 导入器只认本软件导出的那套表头（12 列，按列名对位）。
  从 1Password / Bitwarden / Chrome 直接导出的 xlsx 不会认 —— 它们的列名与
  结构不同。要迁移只能先把列名改成那 12 个（前 9 列就够，缺的列按空处理）。
  做通用映射需要逐个适配各家导出格式，当前不做。
- **库文件跨设备。** 这是本产品的核心形态，不是待办：
  库文件绑定本机，换电脑、重装系统、换主板、改计算机名都打不开。
  **数据可以跨设备**——走「旧机导出 Excel → 新机建库 → 导入」三步，
  见 [BACKUP.md](BACKUP.md)。需要「同一个库文件在多台机器上直接打开」的人，
  应该选用其他工具。
- **云同步。** 同上，与「数据不出这台机器」的定位冲突。
- **浏览器插件。** 会引入一整套 WebExtension 的维护成本，而全局热键已经
  覆盖 90% 的使用场景。
- **多用户 / 共享库。** 单用户单库是这个产品的定位。
- **多语言界面。** 界面只有简体中文。安装包里的语言选项只影响安装向导，
  与界面无关。

## 已知限制

- 中文为主的库（一万条以上全中文条目）搜索约 1 ms，比其他场景慢一档。
  原因与取舍写在 `docs/PERFORMANCE.md` §6。
- 剪贴板定时清除挡不住系统剪贴板历史（Win+V）。要彻底解决需实现
  「模拟键入」而不是「复制粘贴」，排在 v1.1。
- `parallelism` 字段当前不加速（未启用 Argon2 的多线程实现）。
- 开启免密码模式后，本机上进入库不再需要主密码（DPAPI 封存主密钥）。
  默认关闭，开启前需勾选确认，详见 README「免密码模式」。
- 软件以解锁状态运行时，Tauri IPC 不校验调用方 —— 本产品信任
  「已登录的这个 Windows 用户」运行的所有程序。
