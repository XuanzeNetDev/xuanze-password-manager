## v1.1 —— 便捷性

用户抱怨最多的会是「每次都要切窗口再复制」，所以这一版全在解决这个。

- [ ] **全局热键**：`Ctrl+Alt+Space` 唤起一个只做搜索的小窗，
       `Enter` 直接复制并隐藏。不打开主界面。
- [ ] **快速输入**：选中条目后模拟键盘输入（不是粘贴），绕开剪贴板历史工具。
- [ ] **TOTP 支持**：存 `otpauth://` 种子，直接显示 6 位码并带倒计时。
       密钥管理场景下这几乎是必需项。
- [ ] **过期提醒**：启动时列出已过期 / 临期的密钥（`expires_at` 字段已经在用）。

## v1.2 —— 规模与稳健

- [ ] 增量保存：只重写变化的条目（当前是全量重加密，5 万条 400 ms）
- [ ] 大库分段加载：打开时先只解密索引，正文按需拉取
- [ ] 库文件历史版本（保留最近 N 次快照，防误删）

## 明确不做

- **无保护的导出。** 导出功能是有的（Excel，按专辑分表），但必须再输一次主密码，
  且文件是明文 —— 这是自觉的取舍：备份与迁移是真实需求，装作不存在只会让人
  用更危险的方式自己解决。
- **跨设备 / 换机恢复。** 这是本产品的核心形态，不是待办：
  库文件绑定本机，换电脑、重装系统、换主板、改计算机名都打不开。
  需要跨设备的人应该选用其他工具。
- **云同步。** 同上，与「数据不出这台机器」的定位冲突。
- **浏览器插件。** 会引入一整套 WebExtension 的维护成本，而全局热键已经
  覆盖 90% 的使用场景。
- **多用户 / 共享库。** 单用户单库是这个产品的定位。
- **多语言界面。** 界面只有简体中文。安装包里的语言选项只影响安装向导，
  与界面无关。

## 已知限制

- 中文为主的库（一万条以上全中文条目）搜索约 1 ms，比其他场景慢一档。
  原因与取舍写在 `docs/PERFORMANCE.md` §6。
- 剪贴板定时清除挡不住系统剪贴板历史（Win+V）。要彻底解决需实现
  「模拟键入」而不是「复制粘贴」，排在 v1.1。
- `parallelism` 字段当前不加速（未启用 Argon2 的多线程实现）。
- 解锁后 12 小时内，进入库凭据是本机 Windows 用户身份而非主密码。
  详见 README「解锁票据」。
- 软件以解锁状态运行时，Tauri IPC 不校验调用方 —— 本产品信任
  「已登录的这个 Windows 用户」运行的所有程序。
